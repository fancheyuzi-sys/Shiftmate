# ShiftMate — 澳洲工时工资日历 (PWA)

这是**可操作的 V1 原型**，不是经过法律或薪资专业审计的正式工资计算工具。

## 免费放到 GitHub Pages（手机 / iPad 均可）

1. 登录 GitHub，点击右上角 **+ → New repository**，仓库名填 `shiftmate`，Visibility 选 **Public**，点击 **Create repository**。
2. 在新仓库点击 **Add file → Upload files**，上传本文件夹**里面的全部文件和 `icons` 文件夹**（不要只上传 ZIP；`index.html` 必须在仓库根目录）。点击 **Commit changes**。
3. 进入仓库 **Settings → Pages**，在 **Build and deployment** 下选择 **Deploy from a branch**，分支选 `main`、文件夹选 `/(root)`，保存。
4. 等待 GitHub 显示站点网址，再从该 HTTPS 地址打开。网址通常具有 `https://用户名.github.io/shiftmate/` 的形式，**以 GitHub 实际给出的地址为准**。
5. 浏览器打开后可添加到手机主屏幕：iPhone 的 Safari 分享→添加到主屏幕；Android 的 Chrome 菜单→安装应用/添加到主屏幕。

> 首次打开需要联网。更新文件后再次联网打开页面，才能获取最新版本；离线时会使用缓存。换了域名或路径，浏览器会视为不同站点，原有本地工资数据**不会自动迁移**；请先用设置页导出加密备份。

## 隐私与存储

- 所有工资记录、工作模板、设置、工资单都只在**当前浏览器 + 当前网址**的 IndexedDB 中。
- 网站只托管公开的 HTML/JS/CSS/PWA 图标和缓存脚本，不提供账户，也没有接收工资数据的后端。
- 工资和税务计算全在设备浏览器本地完成；加密备份在设备本地使用 Web Crypto (AES-256-GCM + PBKDF2) 生成和恢复。
- 手动备份是必须的：清理浏览器数据、卸载、无痕模式或系统回收存储可能导致数据丢失。不同手机之间不会自动同步。
- **公共仓库会公开源代码，但不会包含运行时 IndexedDB 工资记录。** 不要把个人工资备份文件或真实工资单上传到仓库。
- 正常访问网页仍可能产生 GitHub 托管方的访问日志。

## 当前可使用

8 列月历、跨月整周、日工时编辑、多份工作、工作预设、批量填充、复制上周、基本及加班/节假日工资估算、税务模式、周/月统计、工资单对账、本地 IndexedDB、加密导出与恢复、CSV 导出、离线缓存。

## 重要限制

- 公共假日当前只覆盖部分 QLD 2026/2027 日期，且部分地方节日须手动补录；**不能当作完整澳洲公共假日库**。
- 加班由用户填写时数；未自动从每种 Award/Enterprise Agreement 推导加班门槛。
- 税额是简单百分比或 WHM 分段年度估算，不代表雇主真实 PAYG 预扣；Super 也是简化估算，须以雇主工资单和适用法律核对。
- 有薪/无薪休息在跨公共假日班次中按比例估算；部分复杂薪酬组合需额外校验。
- 提供 **Excel 可打开的 CSV**，不包含原生 `.xlsx` 文件。
- 不会自动将数据发送到朋友手机，每人打开同一网页各自使用独立数据。

## 更新

以后要更新 APP，只需要修改仓库里的网站文件并提交；新的页面会通过 Pages 发布。**不要删除用户在设备上的站点数据**。
