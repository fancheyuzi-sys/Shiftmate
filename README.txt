ShiftMate 澳大利亚工时与工资 PWA · V1.0 可交互原型

使用方法：
1. 可直接打开 index.html 查看界面和体验计算。部分浏览器对 file:// 的 IndexedDB 或 Web Crypto 有限制；实际稳定使用请用 HTTPS 网页托管。
2. 如需手机添加到主屏幕及离线打开，将整个文件夹上传到支持 HTTPS 的静态网站托管，例如 GitHub Pages、Netlify、Cloudflare Pages。托管的是网页代码；工资数据保留在每位用户自己的设备内。
3. 每个人打开相同链接都可以创建自己的独立本地记录，不需要登录。
4. 请及时通过「设置与备份」导出加密备份文件并记录密码。

本原型已有：月度八列日历、同日多份工作、班次预设、批量填充、复制上周、普通/加班/公共假日时数与薪资、分段倍率与固定时薪、夜班与周末普通工时津贴、跨午夜部分公共假日判定、2026/27 昆州基础节假日、地区节假日、税务简化估算、Weekly/Fortnightly 工资单对账、Super 简化估算、加密导出与恢复、Excel 兼容 CSV、IndexedDB、Service Worker。

已知限制：
- 未完整覆盖澳洲所有州与地区的法定公共假日；2026/27 昆州基础节假日和选定地区日历仅供原型体验。外州需手动补录。
- 每日工资由用户填写的加班时数驱动，不自动判断 Award 的加班门槛。休息在计算中统一视作减去无薪休息，无法精确判断休息落在何种加班/公共假日区间。
- 估算税额是固定百分比或 WHM 年度累计分段税额，不等同工资单 PAYG 预扣数额，不包含复杂个人税务情况。
- Super 计算为近似示例；没有逐个 Award 核实 Ordinary Time Earnings 计算基数。
- 工资单只对账同日期范围内的合计，若多位雇主或不同发薪日交叉要分别复核。
- 「复制上周」以今天所在周（或当前展示月第一周）为目标。未提供任意多日期批量修改或真正 Excel .xlsx 导出。
- 没有服务器或用户账户；卸载浏览器/清除网站数据会丢失未备份记录。

隐私：不包含任何第三方脚本、跟踪代码、分析接口或后端 API；浏览器从托管站下载网页文件可能留下正常的 HTTP 访问日志，但不会主动上传工资记录。

注意：工资、税率、Super、节假日的正式计算应按实际适用的 Award、Enterprise Agreement、ATO 和州政府规定核对。原型不能代替专业薪资软件。
